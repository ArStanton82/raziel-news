Hermes Agent v0.23.1

Nov 10, 2026

Overview

v0.23.1 — The Cap Release. Released November 9, 2026. Since v0.23.0: ~618 merged PRs · 2,578 non-merge commits · 2,781 changed files (+151,690 / −62,595) · 409 closed issues, measured at commit 3b421578588.

This is not a feature release; it is a stability tag that pins the window for the GitHub release (CLI and installers), the Microsoft Store app, Docker and Hermes Cloud. The release notes are explicit about the rest: most of what landed in this window is undocumented here on purpose, and the full curated notes ship with v0.24.0, covering everything from v0.23.0 onward.

So the one thing this version is really about is why a plugin you can see on the site would not install.

Highlights

1. Plugin catalog cap: 2 MiB to 16 MiB

The published plugin catalog crossed the client’s 2 MiB acceptance limit on November 9. Past that limit the fetch is treated as a broken response: the client logs at debug level, returns “no live catalog,” and falls back to the copy shipped inside the installation. Nothing surfaces to the user.

Three consequences, the third being the bad one:

  • newly listed plugins do not exist on that machine;
  • plugins re-pinned to newer commits install at the pin the release shipped with;
  • newer removed entries are invisible, so a plugin that has been formally pulled still looks installable.

This patch moves the cap to 16 MiB (#151860, fixes #151856). At current per-entry sizes that fits roughly 9,000 entries while still bounding a hostile or corrupted response. Installs staying on v0.23.0 or older keep falling back until they update.

2. What the window holds but does not document

The notes list what landed in this window without expanding it here:

  • Esc backtrack in the TUI and the classic CLI, replacing the rewind list picker;
  • group chats that run on a gateway without Desktop, able to seat bots from other computers;
  • saved gateway connections shared by Desktop and the Webapp;
  • the in-app browser signing in with your real browser profile and filling saved logins from its address bar;
  • hermes gateway attach for local clients;
  • hermes clipboard image --json;
  • new plugin API: session-scoped environment values, plugin JSON-RPC methods and events, llm.oneshot auxiliary tasks, a compression-stable conversation_id, an on_session_open gateway hook and a post_curator_run hook;
  • faster transcript and handoff reads, plus a large batch of new catalog entries.

Fixes

Problem Result
Published catalog larger than the 2 MiB client cap Cap raised to 16 MiB; the live catalog is used again
Silent fallback to the in-tree copy Behavior kept (the fallback is correct), the reason stays in the debug log
Missing new plugins, stale pins, absent removals Gone with the cap fix

Upgrade

hermes update
  • Microsoft Store app: updates through the Store;
  • Desktop installed from the .exe / .dmg installer: unchanged in this release, follows the next bundled release;
  • Docker / Hermes Cloud: nousresearch/hermes-agent:stable (or :latest).

After upgrading, verify once: install a plugin you could not find before. Background and a self-check procedure are in this release write-up.
